# Retrospective wireframes

Created **28 October 2026** as a retrospective design review. These files are **not original planning**, earlier sprint evidence, application screenshots, or proof of deployment/payment/marketing success.

- [Editable HTML wireframes](wireframes.html)
- [Desktop rendered overview](wireframes-desktop.png)
- [Mobile rendered overview](wireframes-mobile.png)

The six layouts cover home, shop, cart, the transition to Stripe-hosted checkout, blog reading/CRUD and the new owner-only pet-profile workflow. Symbolic boxes are deliberately used instead of invented product photographs, customer records or a copied Stripe/Facebook interface. The pet-profile diagram must remain consistent with the final implemented fields and controls.

The PNGs are genuine local Chromium renders of `wireframes.html`, retaining the retrospective date/disclosure. They are design diagrams, not screenshots of the running app. Retain genuine original wireframes if the owner has them and identify their actual provenance separately.
